# ⚙️ Retail Billing System – Backend (Spring Boot & Mysql)

This is the **backend** of the Retail Billing System project, developed using **Spring Boot** and **MySQL**.  
It provides RESTful APIs for managing Items, customers, and billing details.

---

## 🚀 Tech Stack
- ☕ Java 21 
- 🌱 Spring Boot 3.2.5
- 🧩 Maven
- 💾 MySQL
- 🧪 Postman (for API testing)
- ☁️ Railway (for deployment)

---

## 📦 Features
- RESTful API endpoints
- CRUD operations for Items
- MySQL database integration
- CORS support for React frontend
- Easy deployment configuration
